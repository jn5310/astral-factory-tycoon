# Astral Factory Tycoon

**공장을 짓고, 밤을 버티고, 행성을 탈출하라.**

공장 자동화와 타워 디펜스를 합친 모바일 우선 브라우저 게임입니다. Mindustry와 Factorio에서 영감을 받았습니다. 외계 행성 Astra IV에 착륙해 광물을 캐고, 벨트로 생산을 자동화하고, 밤마다 몰려오는 외계 생명체를 막아 내며, 부품 1,000개로 만든 탈출 로켓을 쏘아 올리세요.

이미지 파일과 사운드 파일을 하나도 쓰지 않습니다. 모든 그래픽은 HTML5 Canvas로 그리고, 효과음과 배경 음악은 Web Audio API로 실시간 합성합니다.

**▶ 브라우저에서 바로 플레이:** https://jn5310.github.io/astral-factory-tycoon/
휴대폰과 PC 모두 지원합니다. 무료이고 광고·추적·계정이 없습니다. 한국어와 영어(English)를 지원합니다.

## 주요 기능

**공장과 물류**
- 시드로 생성되는 120×120 행성. 광물 6종(철, 구리, 석탄, 돌, 실리콘 모래, 티타늄)과 물, 암반 지형.
- 아이템 30종, 레시피 24종. 광석에서 판재, 기어, 회로, 배터리, 프로세서, 로켓 부품까지 이어지는 생산 트리.
- 물류 블록 8종: 컨베이어 벨트, 고속 컨베이어, 분배기, 교차 다리, 지하 터널 벨트, 필터 분류기, 창고 컨테이너, 투입기. 앞이 막히면 벨트 위 아이템이 하나씩 정체됩니다.
- 스마트 드래그 건설: 손가락으로 쭉 그으면 직선과 코너가 한 번에 깔립니다.
- 청사진: 영역을 복사해 이름을 붙이고, 원하는 곳에 회전해서 붙여넣습니다.
- 화력 발전기, 태양광 패널, 대형 축전지, 전신주로 이루어진 전력망. 과부하가 걸리면 그 전력망의 기계 전체가 느려집니다.
- 5단계 35개 노드의 연구 트리.

**방어**
- 외계 생명체 8종. 떼로 몰려오는 러셔부터 다섯 번째 밤마다 나타나는 보스 레비아탄까지 있습니다. A* 길찾기로 성벽을 돌아가고, 막히면 가장 약한 벽을 부숩니다.
- 포탑 6종과 성벽. 실탄 포탑은 벨트로 탄약을 받아야 하고, 레이저·냉각·수리 포탑은 전력을 씁니다.
- 기계가 오염을 퍼뜨리고, 오염이 둥지에 닿으면 낮에도 습격이 옵니다.
- 포탑은 처치 수에 따라 신병, 베테랑, 정예, 에이스로 진급하고, 계급마다 공격력이 15%씩 오릅니다.
- 처치한 외계 생명체는 코어로 전리품을 남깁니다.

**캠페인과 반복 플레이**
- 튜토리얼을 겸하는 임무 24개. 관제 센터 무전과 보상이 함께합니다.
- 임무로 해금되는 사령관 능력 4종: 궤도 폭격, 긴급 수리 나노봇, 오버클럭, 냉각 펄스.
- 무작위 이벤트 6종: 풍부한 광맥을 남기는 유성우, 탭해서 줍는 보급 캡슐, 태양 폭풍, 모래 폭풍, 광맥 활성화, 붉은 달.
- 모드 3종: 캠페인, 샌드박스(전부 해금, 무료 건설), 일일 도전(그날은 모두가 같은 행성과 변수로 플레이).
- 평화부터 악몽까지 난이도 5단계. 난이도별 점수 배율이 있습니다.
- 항목별 점수, 기기 내 상위 10개 기록, 오늘의 최고 점수, 스크린샷 공유 버튼.
- 업적 21개와 새로운 종을 만날 때마다 채워지는 외계 생명체 도감.
- 평온, 긴장, 보스 테마를 오가는 적응형 배경 음악.
- 60초마다, 그리고 페이지를 벗어날 때 자동 저장. JSON 내보내기·가져오기 지원.

## 직접 실행하기

Node.js 22가 필요합니다.

```bash
npm install
npm run dev      # 개발 서버
npm test         # Vitest 단위 테스트 (10개 스위트, 147개)
npm run build    # 타입 검사 + dist/ 로 프로덕션 빌드
```

`dist/`는 상대 경로(`base: './'`)를 쓰므로 같은 빌드가 GitHub Pages, itch.io 등 어떤 정적 호스팅에서도 돌아갑니다. `main`에 푸시할 때마다 `.github/workflows/deploy-pages.yml`이 테스트, 빌드 후 GitHub Pages에 배포합니다.

**기술 스택:** TypeScript (strict) · React 19 · HTML5 Canvas 2D · Tailwind CSS 4 · Vite · Vitest. 그 밖의 런타임 의존성은 없습니다.

## 프로젝트 구조

```
src/
├── core/       게임 루프(Game), stepWorld, 카메라, 입력, 건설 컨트롤러, 렌더러, 미니맵, 저장/불러오기, 프로필
├── entities/   Building, Enemy, Projectile/Particle(오브젝트 풀), Pickup
├── systems/    벨트, 물류, 생산, 전력, 연구, 길찾기(A*), 적 AI, 전투, 웨이브, 오염,
│               임무, 사령관 능력, 무작위 이벤트(director), 업적, 점수 등
├── data/       아이템, 레시피, 건물, 연구, 적, 포탑, 임무, 이벤트, 난이도, locales/
├── ui/         React HUD (타이틀 화면, 상단 바, 건설 바, 정보 패널, 연구 트리, 각종 패널과 오버레이)
├── utils/      i18n, 수학, 난수, 펄린 노이즈, 포맷터, Web Audio 효과음·음악, 공유, 일일 시드
└── test/       Vitest 테스트
```

시뮬레이션은 DOM에 손대지 않는 결정적 60 Hz 고정 스텝(`src/core/engine.ts`의 `stepWorld`)입니다. 브라우저 루프와 테스트가 같은 코드를 돌립니다.

## 다국어 지원

화면에 보이는 모든 문구는 `src/data/locales/`에 있습니다. `types.ts`가 `Messages` 인터페이스를 정의하고 `en.ts`, `ko.ts`가 이를 구현합니다. 각 항목은 문자열이거나 작은 포맷 함수라서 언어마다 복수형과 어순을 올바르게 맞출 수 있습니다. 처음 실행할 때 브라우저 언어를 따라가고, 타이틀 화면이나 설정에서 바꿀 수 있습니다.

언어를 추가하려면 `en.ts`를 복사해 번역하고, `src/utils/i18n.ts`의 `LANGS`, `MESSAGES`, `isLang`에 등록하세요. 테스트가 모든 언어의 키가 같은지, 빈 문자열이 없는지 검사합니다.

## 테스트

`npm test`는 10개 스위트, 147개 테스트를 실행합니다. 벨트 이동과 정체, 모든 물류 블록, 전력 수지와 전력망 분리, 레시피·연구 데이터 정합성, A*(브루트포스 다익스트라와 최적성 비교, 모서리 통과 금지, 지형 가중치), 적 AI, 지형 생성, 드래그 건설, 청사진, v1 세이브를 포함한 저장·불러오기 검증, 임무, 사령관 능력, 무작위 이벤트, 전리품과 진급, 난이도와 일일 도전, 점수, 업적과 프로필, 적응형 음악 패턴, 두 언어의 번역을 검사합니다.

## 개인정보

게임은 로드된 뒤 네트워크 요청을 보내지 않습니다. 분석 도구, 광고, 계정이 없습니다. 세이브, 설정, 최고 기록, 업적은 브라우저의 localStorage에만 저장됩니다. 사이트 데이터를 지우면 함께 지워지니 **메뉴 → JSON 내보내기**로 백업해 두세요.
